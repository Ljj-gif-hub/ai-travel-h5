# 西安旅游攻略

## 交通
西安咸阳机场乘机场城际约40分钟到市区。地铁2号线南北贯穿城区。市内景点密集，地铁+步行即可；兵马俑在临潼，需乘地铁9号线+接驳或旅游专线。

## 住宿
钟楼/南门（永宁门）附近最方便，地铁换乘、回民街美食都在步行范围。大雁塔周边看夜景方便。城墙内住宿更有古城氛围。

## 必去景点
兵马俑是世界奇迹，建议请讲解或租讲解器，预留半天。华清宫、骊山可与兵马俑同线。陕西历史博物馆免费但需提前5天抢票，馆藏极丰富。城墙骑行一圈约2小时，傍晚最美。大雁塔北广场音乐喷泉、大唐不夜城夜景。

## 美食
回民街以牛羊肉泡馍、肉夹馍、凉皮、镜糕为主，推荐老孙家泡馍、贾三灌汤包。洒金桥、北院门是老西安更本地化的选择。葫芦鸡、biangbiang面、油泼面都是必尝。

## 行前贴士
春秋最佳，夏季酷热。陕博、兵马俑需提前预约购票。城墙骑行租车有押金。回民街游客多，注意防宰。夜间大唐不夜城灯光秀值得一看。
