# 成都旅游攻略

## 交通
成都双流/天府两大机场，天府较远建议选双流。地铁覆盖核心区，宽窄巷子、锦里、春熙路都在地铁沿线。市内共享单车多，骑游老城区很惬意。

## 住宿
春熙路/太古里商圈最方便，逛街、美食、地铁俱全；宽窄巷子周边有文艺民宿；高新区性价比高但离景区远。建议住2号线/4号线沿线。

## 必去景点
大熊猫繁育研究基地看"滚滚"要早上8点前到（熊猫上午活跃）。宽窄巷子、锦里、武侯祠、杜甫草堂都在市区，2天可逛完。都江堰+青城山一日游，拜水都江堰。人民公园鹤鸣茶社体验盖碗茶。

## 美食
火锅必吃——蜀大侠、大龙燚、小龙坎任选，微辣是底线。串串香、钵钵鸡、担担面、甜水面各有名店。锦里小吃街集大成，玉林路有玉林串串。喝个盖碗茶、看个川剧变脸。

## 行前贴士
成都"慢生活"，行程别排太满。火锅店多需排队，提前取号。熊猫基地节假日人爆满，错峰出行。夏季闷热、冬季湿冷，随身带伞。
