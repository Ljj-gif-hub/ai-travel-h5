# 广州旅游攻略

## 交通
广州地铁四通八达，白云机场经3号线约40分钟到市区。高铁南站、东站均接驳地铁。市区建议地铁+步行，老城区（越秀、荔湾）街巷多适合骑行探索。

## 住宿
珠江新城（天河）是CBD，酒店新、地铁方便；越秀老城区（北京路、上下九）近历史景点，性价比高；琶洲近会展。地铁1号线沿线串联多数景点。

## 必去景点
沙面岛欧陆建筑群适合漫步拍照，广州塔登塔看珠江夜景（分时段票价）。陈家祠岭南建筑代表，南越王墓博物馆小众精品。长隆欢乐世界/野生动物世界需一整天，网上提前购票。

## 美食
广州是"食在广州"——早茶推荐白天鹅、广州酒家、点都德，虾饺烧卖肠粉必点。烧鹅、白切鸡、煲仔饭各有名店。北京路、上下九小吃街，甜品选双皮奶、杨枝甘露。

## 行前贴士
夏季湿热，注意防暑带伞；冬季温暖适合避寒。广州塔、长隆人流大需提前预约购票。粤语通用普通话无障碍。地铁站多设有便利店。
